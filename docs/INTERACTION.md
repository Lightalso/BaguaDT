# 交互与装配操作

本文描述当前版本的编辑器交互。设计目标是让视口、属性面板和装配编排遵循 Unreal Editor / Unity Editor 的常见习惯，而不是把功能堆成互不相干的按钮。

## 视口与选择

| 操作 | 行为 |
| --- | --- |
| 左键点击 | 选择一个对象 |
| 左键双击 | 选择并聚焦该对象 |
| 空白处左键 | 取消选择 |
| F | 聚焦选中对象 |
| Ctrl+Home | 框选全部可见对象 |
| Home | 重置相机 |
| 右键按住 | 原地转向；W/S 前后、A/D 左右、Q/E 下上 |
| 右键按住时 Shift / 滚轮 | 加速漫游 / 调整漫游速度 |
| Alt+左键拖动 | 环绕 |
| 中键拖动 | 平移 |
| 滚轮 | 缩放 |

选中对象使用蓝色轮廓描边，悬停对象轻微提亮。场景树支持按名称 / 类型过滤，并可从右键菜单把对象直接设为装配的部件 A / B。

## 变换操作柄

工具快捷键沿用 Unity 的 W / E / R：

| 工具 | 操作柄 |
| --- | --- |
| W 移动 | 三根轴向箭头、三个平面柄（YZ / ZX / XY）、中心方形柄（屏幕平面移动） |
| E 旋转 | 三个轴向环、外圈屏幕空间旋转环 |
| R 缩放 | 三根局部轴、中心方形柄（均匀缩放） |

- **L** 切换世界 / 局部坐标系。移动和旋转受此设置影响；缩放的三个分量本身定义在局部空间。
- **G** 开关吸附。拖动过程中按住 **Ctrl** 可临时吸附，即使开关处于关闭状态。
- **Shift** 使用精细步长：吸附时为步长的 0.1 倍，未吸附时约为鼠标位移的 0.15 倍。
- 拖动时视口左上角 HUD 显示当前工具、坐标系、吸附步长、对象坐标和本次增量；状态栏也显示增量。
- 每次拖动生成一条撤销记录；Esc 取消整个拖动并恢复拖动前的状态。

### 吸附与键盘微调

工具栏的“步长”同时决定平移和缩放步长，并据此选择旋转步长（0.01 / 0.05 / 0.10 对应 5°，0.25 / 0.50 / 1.00 对应 15°）。

选中对象且视口获得焦点时：

- ↑ / ↓：沿世界 Z 轴微调
- ← / →：沿世界 X 轴微调
- PageUp / PageDown：沿世界 Y 轴微调
- 按住 Shift 时步长放大 10 倍

这些按键每次生成一条“微调对象”撤销记录。

## 属性面板

- 数值框可以直接输入，也可以按住鼠标在文字区域水平拖动来刷值；Shift 让刷值更精细。
- Esc 把字段恢复为获得焦点前的值。
- 每行末尾的 ↺ 把该行恢复为默认值：位置 0、旋转 0、缩放 1、尺寸 1（平面为 6 × 1 × 6）。
- 分组标题前的复选框可以折叠分组，和 Unreal Details 的 Section 行为一致。
- 位置 / 旋转 / 缩放 / 尺寸保持相互独立；几何尺寸与缩放相乘得到最终尺寸。

## 装配（约束）界面

右侧“装配 · 约束”页签（与属性页签并列）是约束编排工作区。上方是约束列表，下方是编排器；运行时的实时值显示在列表的状态列，鼠标悬停列表可查看完整诊断。

### 创建一条约束

1. 在场景中选择一个部件。没有选中已有约束时，编排器默认把它放进 **部件 A**，并把另一个部件放进 **部件 B**。
2. 也可以点 **视口拾取**：先点 A，应用会自动进入 B 的拾取；Esc 取消。
3. 点 **两部件中点**、**A 中心**、**B 中心** 或 **视口拾取连接点** 设置一个共同的世界连接点。两侧的局部锚点会自动换算，保证连接点在空间中重合。
4. 选类型：移动副 / 转动副 / 球铰 / 固定副 / 转动约束 / 缝合。不同类型会显示相应的轴、限位、驱动、阻尼或缝合参数。
5. 轴向可使用世界 X / Y / Z，也可使用“A 局部”的 X / Y / Z（按部件 A 当前旋转换算），或点“反向”。
6. 需要精确的局部锚点时展开“高级 · 局部锚点”，直接编辑 A / B 的体坐标，或使用视口拾取。
7. 点 **＋ 新建约束**。创建后约束会出现在上方列表并被选中，视口同时高亮它的锚点和轴线。

**清空** 会取消列表选择，并用当前选中的部件重新开始一条新约束，不会修改已有约束。**应用** 把编排器写回当前选中的约束，**删除** 删除它。右键列表项还可以聚焦连接点或复制约束。

### 约束列表与诊断

- 列表列：类型、部件 A → B、参数 / 实时值。选中一行会立即把参数载入编排器。
- 视口突出显示选中约束的 A / B 锚点、连接线、轴向和类型标签；其他约束降低透明度。
- 运行物理模拟后，列表状态列会显示每条约束的实际行程 / 角度 / 缝合误差、驱动目标、阻尼力和限位越界标记；悬停列表项可查看完整诊断。
- 编辑期间所有约束修改都进入撤销栈；模拟运行期间编辑被锁定，重置后恢复。

### 锚点页

- **在物体中心添加**：把锚点放在当前选中刚体的几何中心。
- **在视口点选添加**：点击物体表面添加锚点。
- **吸附**：可选表面（自由）、最近顶点、面中心、网格顶点。装配连接点通常应使用顶点或面中心，避免浮点误差。
- 选中锚点后可精确编辑 X / Y / Z 并“更新锚点”；删除锚点会同步修复引用它的缝合对。
- 锚点保存为物体局部坐标（米），跟随平移、旋转和 scale。

### 缝合 / 弹簧配对

缝合约束的配对不再要求手动输入“锚点序号”：

- 表格每行包含 **A 锚点下拉框**、**B 目标**和 **世界距离**。
- A 下拉框直接显示 `#序号 (世界 X, Y, Z)`；B 目标在网格模式下显示 `顶点 #序号 (世界 X, Y, Z)`。
- 选择配对行后，点 **拾取 A** 再点部件 A 表面，会自动选最近的 A 锚点；随后自动进入 **拾取 B**，点部件 B 表面自动选最近的网格顶点（勾选“两侧都是锚点”时选最近锚点）。
- **添加** 会选下一个未使用的 A 锚点，并自动匹配最近的 B 目标，可在表格中继续调整。
- **自动配对** 为每个 A 锚点匹配最近的未使用 B 目标。
- 表格下方实时显示 A/B 世界坐标和距离；选中行会在视口高亮 A 锚点。
- “两侧都是锚点”切换时，B 列会改为 B 锚点下拉框；切换后请重新确认 B 目标。

### 接触排除页

用于关闭指定部件对之间的接触。对故意重叠的装配体（导柱与滑块、轮毂与轮辋、胎唇与轮辋）必须先排除接触，否则求解器会因为初始相交拒绝启动。

## 视口信息与装配显示

- 左上角变换提示已压缩为一行半透明状态条，只显示当前工具、坐标系和吸附状态；拖拽时的反馈也复用它，不再用大块白色卡片遮挡模型。
- `Ctrl+Shift+H` 或 **视图 → 显示工具提示** 可完全关闭这一行。
- `Ctrl+Shift+L` 或 **视图 → 显示装配关系** 控制装配连线；装配页签筛选框右侧的 **视口** 复选框与它同步，可以随时关闭全部连线和标签。
- `Ctrl+Shift+A` 或 **视图 → 显示锚点** 单独控制锚点标记，不再和装配连线绑死。
- 选中约束后，视口会加粗显示它的连线、在两端标出 `A` / `B`，在标签中显示类型和两个部件名，并用虚线包围两个部件；未选中的装配只保留低对比度连线。
- 缝合约束会为每一对连接绘制连线；选中时显示 `缝合 · A ... ↔ B ... · N 对` 标签和端点。

## 从组件到整车（纯 GUI 流程）

目标流程是 **导入组件 → 用装配向导生成四轮悬挂/轮胎缝合 → HSC 仿真 → 录制**，不需要命令行或手写 JSON。支持两种入口：

1. **已有整车场景拆成组件**：打开 `examples/hsc-vehicle/ground_1e8.bagua.json`，在底部「资产记录」页点「拆分全部…」，或使用「文件 → 拆分全部对象为组件…」。每个对象会写成独立的 `.bagua.json` 组件，保留网格、四面体、质量、固定状态和锚点。
2. **已有 OBJ / STL / PLY / MSH 资产**：在「资产记录」页点「导入网格…」，或按 `Ctrl+I`。导入设置中可选择单位、向上轴和是否固定。轮胎应使用带四面体的 `.msh`，否则只能形成刚体轮胎。

逐个导入组件：在「资产记录」页点「导入组件…」，或使用「文件 → 导入组件…」。组件会与当前场景合并，重复 ID 自动重新映射；导入是单条撤销记录。

### 车辆四轮装配向导

打开「工具 → 车辆四轮装配向导…」，或点装配面板顶部的「车辆装配向导…」。向导包含：

- **车架 / 底盘**：选择底盘对象。
- **四轮悬挂表**：FL / FR / RL / RR 四行，每行选择转向节、轮辋、轮胎。对象名符合 `spindle_i`、`wheel_i_rim`、`wheel_i_tire` 时自动匹配，也可点「按名称自动匹配」。
- **松散轮胎表**：可选的 3 组轮辋 + 轮胎，用于轮胎障碍。
- **参数**：悬挂强度、阻尼、行程上下限、弹簧刚度 / 静止长度、驱动速度、轮辋环状锚点数 / 半径、缝合刚度。
- **HSC 预设**：生成后启用 HSC，并应用重力、接触、Newton 迭代等车辆参数。

生成时向导会：

- 把选中的车架、转向节、轮辋、轮胎设为动态；
- 为车架和转向节补足连接锚点；
- 创建 4 组「移动副 + 弹簧缝合 + 转动副」悬挂；
- 对每组轮辋/轮胎按最近顶点建立胎唇缝合；轮辋没有锚点时按局部 XY 平面生成环状锚点；
- 为松散轮胎建立轮辋-轮胎缝合；
- 添加底架-转向节、转向节-轮辋的接触排除；
- 以一条撤销记录提交，随后可 F5 仿真、底部录制。

默认参数和轴向对应 `ground_1e8/ground_1e6` 车辆场景（Y 向上，车轮轴 Z）。若自行导入的整车朝向不同，可在生成后用装配面板逐条修改轴向、锚点和限位。

### 范围说明

- 原始 HSC `geometry.npz` / `tire_tet4.npz` 仍由 `scripts/ImportHSCVehicle.py` 或既有转换场景导入；`.npz` 读取不是本轮 GUI 范围。
- 一旦有了组件资产，上面的拆分、逐个导入、装配、仿真和录制全部可在 GUI 内完成。
- 胎唇自动配对使用最近顶点；对生产级精度要求，可在装配面板的缝合页查看并替换配对。

## 仿真线程与界面响应

物理世界不在界面线程运行：

- 每个场景文档有一个 `SimulationSession`。它在独立的 `QThread` 中创建、推进和销毁 `Physics`（HSC 原生世界或 Chrono），求解器、CUDA 上下文和原生 DLL 调用都发生在该工作线程。
- 工作线程每个刷新周期把 `objects / links / exclusions / time / 接触数 / HSC 统计 / 约束诊断` 复制成一个不可变快照，投递到界面线程；视口和记录器只读取界面侧快照。
- 运行中的仿真由工作线程自己的定时器驱动，界面线程不再用 `QTimer` 推进物理步。暂停后，尚未投递的旧帧不会覆盖界面时间。
- 开始和单步需要返回成功/失败结果，因此会在当前调用栈内启动一个局部事件循环等待工作线程握手；事件循环期间重绘、相机和面板仍然响应，但场景切换和关闭会被暂时阻止，避免启动/单步期间销毁运行时。
- 重置和关闭场景会立即从界面状态中移除运行时，并把销毁请求排入工作线程；随后再次开始会先完成旧运行时的清理，再构建新世界。
- 录制按界面侧快照采样；离线高质量模式让工作线程每个节拍只推进一个固定物理步，并投递一帧。

因此，长时间 HSC 求解、Chrono 步进或世界构建不会阻塞界面主线程。

## 设计约束与已知范围

- 当前选择仍是单对象选择；尚未实现多对象变换和框选多个对象。
- 移动 / 旋转的“局部”是对象自身姿态；旋转的局部模式使用对象局部轴后乘，世界模式使用世界轴前乘。
- 吸附按绝对坐标取整（世界轴）或按位移取整（局部轴），因此世界模式下多拖几次会得到整齐的网格值。
- 旋转欧拉角仍按 Qt `fromEulerAngles` 的 X 俯仰、Y 偏航、Z 滚转约定存储；局部旋转可能在欧拉角上出现等价但数值不同的表示。
- 装配界面沿用现有 `links` 数据模型，没有新增文件字段；旧场景无需迁移。

## 回归测试

`tests/EditorTests.cpp` 中新增：

- `viewportPrecisionHandles`：轴 / 平面 / 中心柄、吸附、世界/局部切换、方向键微调。
- `assemblyPivotComposer`：默认部件选择、共同连接点、约束创建、顶点吸附。
- `simulationRunsOnWorkerThread`：断言物理会话的求解线程不是 GUI 线程。
- `outlinerFilterAndInspectorReset`：场景树过滤和属性行重置 / 撤销。

运行方式见 [VALIDATION.md](VALIDATION.md) 或 `scripts/Build.ps1 -EditorOnly`。
