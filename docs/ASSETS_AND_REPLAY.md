# 资产导入、项目与记录回放

## 导入资产

文件 → 导入网格资产（Ctrl+I）支持多选，选择源文件单位（米、毫米、厘米）与向上轴（Y/Z）。也可直接把模型拖到窗口，此时默认米、Y 向上。

支持 OBJ（对象/组、负索引、多边形三角化、MTL 的 Kd 漫反射颜色）、ASCII/二进制 STL、ASCII PLY，以及 Gmsh 2.2 ASCII 四面体网格（`.msh`，仅线性三角形与四面体单元）。PLY 的 XYZ 属性可以出现在不同列，可带额外的顶点属性。当前不读取贴图、骨骼、FBX、glTF、STEP 或二进制 PLY；需要时应先从建模软件导出上述表面网格格式。OBJ 多边形采用扇形三角化，复杂凹多边形建议由建模软件先三角化。

导入保留源模型的世界位置、尺寸，转换为米、右手系、Y 向上。网格资产在内部以局部包围盒中心作为原点，尺寸与缩放继续使用右侧属性面板；可选择、移动、旋转、缩放、改颜色、复制、删除和撤销。资产记录页显示对象名、顶点数、三角形数、来源文件，悬停可查看原文件 SHA-256 与资产 ID；点击关联场景树，双击聚焦。

只有含四面体单元的 `.msh` 会成为变形体（「弹性体 · FEM」属性可用）：它直接使用文件中的四面体与表面三角形，默认不固定、不约束底面，可自由下落。表面网格（OBJ / STL / PLY）仍是刚体；需要变形行为时请导入四面体资产，或把立方体设为弹性体由程序自行划分。

保存场景时，几何数据内嵌在 `.bagua.json` 的 `assets` 表，实例通过资产 ID 引用。复制对象复用同一不可变网格；删除原始 OBJ/STL/PLY 文件不影响保存后的场景。来源路径是审计信息，不是运行依赖。

导入对象默认固定、开启碰撞。固定网格使用三角面碰撞，允许凹形表面；取消固定后使用动态凸包，凹洞会被凸包填充，质量惯量使用包围盒近似。零体积表面不能作为动态凸包，请保留固定状态。精确多部件凹体应预先拆分成多个凸部件。四面体资产默认是自由变形体，不受这条凸包规则限制。原生 HSC 后端要求动态刚体的表面封闭（每条边由两个三角形共用），内置几何已满足，导入的非封闭网格会在启动时被明确拒绝。资产大小上限 256 MB，单网格最多 100 万顶点、200 万三角形，单场景最多 200 万网格顶点；本版未承诺大型 CAD 装配性能。

## 本机仿真录制

1. 编辑场景并设置刚体碰撞、质量、固定状态和初始速度。
2. 建立运行时并录制，有两种入口：
   - 顶栏「开始模拟」建立物理运行时（Chrono 或原生 HSC 后端），再在底部点击「● 录制」；
   - 或直接点击底部的「▶● 模拟并录制」，一步启动模拟并开始录制。
   两种方式都从当前状态记录，时间从零开始；「● 录制」本身不启动或恢复模拟。
3. 可暂停、继续或单步推进。默认按实时采样：每次视口更新后保存已推进的物理状态，初始状态也会保存；机器较慢时帧间距会变大。
4. 需要稳定帧间距时勾选「离线高质量」：录制期间每个节拍只推进**一个**物理步并记一帧，不追实时。单步耗时较高时整个运行会比真实时间慢，但每帧间距等于场景 dt，回放不会因为卡顿跳帧。该开关可以在录制中随时切换，切换只影响之后的帧。
5. 点击「停止录制」。记录进入上方的记录列表，选中后点「保存录制记录…」写入 `.brec`。日志会给出帧数、时长与平均帧间距。重置仿真保留录制结果。

录制只接受固定的对象列表与网格拓扑。每个页签拥有独立的场景、物理状态、**录制列表**、采样模式和回放游标。未保存记录通过页签 `●` 和面板文字提示，关闭场景或退出应用会询问保存；新的录制不再覆盖已有记录。

## 记录列表

记录栏顶部列出当前场景的全部录制结果，每行显示序号、帧数、时长和状态（未保存 / 文件名 / 录制中）：

- 选中一行即切换到该记录：时间轴、帧号、回放都跟随它；双击直接开始回放。
- 「保存录制记录…」（Ctrl+Shift+R）保存选中的那一条；「删除所选」删除选中的那一条（未保存时会确认，磁盘上的 `.brec` 不受影响）。右键列表也有同样两项。
- 每次「● 录制」或「▶● 模拟并录制」都会新增一条记录，之前的记录继续保留，因此可以在同一场景里比较多次运行。
- 录制进行中列表锁定在当前记录；停止录制后才能切换或删除。
- 关闭页签或退出时，会按条询问未保存的记录；便携项目会带上该场景的全部记录。

两种采样的区别只在于帧的时间分布，物理积分始终按场景 dt 推进（默认 1/240 s）：实时模式按墙钟时间每帧推进若干步，顺带保证交互流畅；离线高质量模式牺牲速度换取等间距采样，适合导出、对比和正式回放。记录元数据的 `sampling` 字段写明是哪一种（`lock-step fixed timestep` 或 `render-tick physical timestamps`），回放时不需要重新设置。

批量录制可以在命令行一次完成，不必停留在界面上逐帧操作：

```powershell
.\dist\BaguaDT\BaguaDT.exe .\examples\hsc-native-contact.bagua.json `
  --hsc on --record run.brec --simulate-steps 240
```

它会启动物理系统、按一个物理步一帧录制，写完 `.brec` 后自动退出；`--simulate-steps` 的上限是 200000 步。分步执行时每个物理步也可能比实时慢，这正是为了得到等间距的高质量记录。需要同时留一张界面截图时可再加 `--capture out.png`，此时窗口不会自动关闭。

## 回放

文件 → 打开回放，或拖入 `.brec`。回放会建立独立页签，不调用原求解器。

- 点击底部「开始回放」「暂停回放」。顶栏和 F5–F8 始终只控制物理模拟；回放期间禁用。当前页签正在模拟时，请先从顶栏重置再回放，录制记录会保留。
- 时间轴可直接点击、拖动；时间输入框可精确跳转到秒。
- 首帧、前一帧、后一帧、末帧按钮按保存快照移动。
- 支持 0.25、0.5、1、2、4 倍速度与循环播放。抵达末帧时停止，再次播放从头开始。
- 「插值」对位置、尺寸、缩放和变形顶点做线性插值，对刚体旋转做四元数球面插值；关闭后显示前一保存帧。插值不是额外的物理计算。
- 回放中可选中、聚焦物体和漫游相机，禁止修改对象。场景树和属性面板显示记录中的对象与变换；变形网格通过完整顶点状态显示。即使编辑场景后来增删了对象，旧记录仍使用录制时的独立对象列表。
- 底部「退出回放」恢复编辑，记录继续保留，可重复查看。

记录在磁盘上按帧压缩、建立索引，载入后仅缓存少数解压帧，拖动无需从第一帧重新计算。支持刚体运动与固定拓扑的变形表面，不支持每帧增删对象或改变网格连接关系。

## 便携项目

文件 → 保存完整项目，将所有页签的编辑场景、内嵌网格和已有记录保存为 `.bagua.project.json` 清单及同级资源目录。每次保存先写新的资源目录，再原子提交清单，旧资源目录保留以避免破坏旧快照。保存后后续 Ctrl+S 指向新项目内的场景文件。

分发项目时复制清单及它引用的整个资源目录。项目引用均为相对路径；不依赖原始资产路径。重新打开恢复页签、场景与记录、当前回放时间和相机，回放默认暂停。撤销历史、窗口布局、实时求解器断点不属于项目文件。

## HSC 示例

文件 → 打开 HSC 车辆回放项目，或双击程序目录的 `OpenHSC.cmd`。也可打开 `examples/HSC/HSC.bagua.project.json`。

两页签来自用户本机 `D:/Collection/HSC_reimpl/result/vehicle_full_pass/` 中已经完成的真实 HSC / libuipc 运行：

| 案例 | 原始物理步数 | 保存快照（含初始帧） | 时长 | 显示对象 |
| --- | ---: | ---: | ---: | ---: |
| 地面胎 E=1e8 Pa | 213 | 108 | 7.100 s | 20 |
| 地面胎 E=1e6 Pa | 209 | 106 | 6.967 s | 20 |

每组含车身/轮辋/悬挂部件、四个车载胎、三个地面胎和显示地面，共 33,509 个网格表面顶点。保存所有已有快照、ABD 仿射表面运动及 FEM 轮胎逐顶点变形；未用刚体轨迹或动画替代变形数据。原项目每两步保存一次快照，并保留最终帧，时间轴依据真实帧号×1/30 s，不把快照误当作 30 FPS。

本节车辆示例回放已有计算结果，没有在 BaguaDT 内重新执行原始车辆 HSC 求解。实时求解入口是工具菜单里的两个示例：HSC 原生接触示例（`examples/hsc-native-contact.bagua.json`）与 HSC 刚柔耦合示例（`examples/hsc-coupled.bagua.json`），需要在物理模拟设置中开启原生后端；见 [HSC 接入说明](HSC_INTEGRATION.md)。原项目的本机 `runtime.json` 与原生后端环境未在该目录提供；重新求解仍需按原项目说明准备带 HSC 补丁的 libuipc。本例的 HSC 结果回放与编辑器内的实时求解是两个独立流程。

车辆使用原复现项目的 Chrono 衍生替代资产，不声称复现了论文原资产或性能。来源状态、参数、求解统计、轨迹与后端指纹在 `examples/HSC/provenance/`；来源和许可在同目录 `SOURCE_NOTICES.md` 与 `Chrono-ASSETS-LICENSE`。原始报告按原文附存为 `original_report.md`，其中链接仍指向原复现仓库的结构。

转换脚本只读取原仓库，输出至 BaguaDT 示例目录：

```powershell
python scripts/ImportHSC.py --source D:/Collection/HSC_reimpl --output examples/HSC
```

转换需要 NumPy，查看示例不需要 Python、Taichi 或 libuipc。`validation.json` 给出首/中/末帧的源坐标检查点，QtTest 会解码两组全部 214 个快照，并将检查点的世界坐标与源数据对照（误差阈值 2e-5 m）。
