# DeepSeek 接手工作审计与修正

审计依据：根目录 `deepseek对话历史.md`、当前源码、Git 基线 `0874221`、本机原复现项目和实际运行结果。对话中的完成声明按各轮范围理解，不能替代源码检查和重新测试。本次没有修改 Chrono 源码，也没有执行对话里提到的 ACL 修改。

## 已保留并复核的工作

- 球与圆柱的封闭网格修复，100 m/s CCD 场景的地板位置修正。
- 多记录列表、逐条保存与删除、便携项目、离线逐物理步采样。
- `links`、体坐标锚点、关节限位、软缝合、接触排除及双轮悬架示例。
- 装配图形界面的初稿。原先最后一轮测试停在关闭窗口：场景仍标记为修改，测试等待保存确认；已修正测试清理，不能把那次未结束的运行算作通过。

## 发现并修正的问题

| 问题 | 修正与证据 |
| --- | --- |
| 求解失败能终止整个进程 | 自有求解器改抛 `SimEngineException`；隔离 SDK 副本的 IPC pipeline 去掉调试用 `noexcept`，让既有 EngineStatus 错误路径生效。故意限制 PCG 到一次迭代，验证返回错误、再次推进被拒绝、重置后可恢复。没有吞掉失败或换用其他求解器。 |
| 可选自适应逆的非有限值、显存不足与迭代超限 | CPU/GPU 都检查失败，退回固定项数 Neumann，并报告 `inverseFallbacks`；非线性求解仍必须收敛。 |
| 删除物体留下悬空链接、排除对或 FEM 连接 | 对象编辑命令同时保存和恢复连接关系；删除自动清理，撤销完整恢复。 |
| 删除锚点导致缝合序号错位 | 一次撤销操作内移除引用该点的缝合对、重排后续序号、删除空缝合。 |
| 同一对物体同类型链接 ID 重复 | 每次创建使用独立 UUID；提交前复用场景加载校验。 |
| UI 与后端锚点坐标不一致 | 统一为体坐标米：平移 × 旋转 × scale，不再额外乘 dimensions。几何尺寸决定形状大小；scale 同时缩放形状和连接点。原有手写物理锚点无需改数值。 |
| 运动/回放中的锚点和轴停留在初始位置 | 原生网格保存四个独立形状顶点的参考基。由逐帧顶点恢复完整仿射坐标系，显示、插值和保存重开都跟随 ABD；不把 12 自由度截断成刚体四元数。 |
| 锚点拾取可能拖动操作柄，添加后继续访问已失效对象指针 | 拾取期间跳过操作柄；提交前复制对象标识与名称；Esc、切换页签、开始模拟会取消拾取。 |
| 限位开关未立即启用输入框、表单重入、选择不同步 | 阻断同步信号，以列表保存的索引寻址；模型修改/撤销后重新加载对应表单，补齐锚点编辑与转动约束参数。 |
| “自动配对”实际上按相同序号配对 | 改为世界坐标下最近且未占用的目标点；提交时校验真实索引范围。刚体间使用两侧锚点模式；B 顶点模式仅用于保持原始节点编号的 FEM，避免刚体网格合并重排后连接到错误顶点。 |
| Chrono 忽略场景 dt、B 侧锚点、限位或接触排除 | Chrono 按实际 dt 推进，使用两个独立局部锚点；尚不支持的限位/缝合/逐对排除明确拒绝启动。 |
| “模拟并录制”不能恢复已暂停系统 | 按钮始终调用开始/继续模拟，再开始新记录。普通录制仍不恢复模拟。 |
| 混合采样被错误标为全程等步长 | 切换采样时记录 samplingChanges；提示使用实际 dt，不再写死 1/240 s。此模式保证状态采样，不提高画面分辨率。 |
| 重开项目可能覆盖已打开页签的记录 | 场景与全部记录先暂存校验，再打开独立页签；不复用和覆盖已有文档。 |
| 回放切换到不同对象数的记录时越界、丢失装配关系 | 比较数量后再访问旧对象；回放预览同步初始场景的链接、排除与 dt。 |
| 命令行失败仍返回 0 | 打开/参数错误返回 2，模拟错误返回 3，记录写盘失败返回 4。 |
| 旧 CMake 缓存的中文 include 前缀乱码造成漏编头文件 | 自动刷新配置并清理旧对象文件；完整版与全新 ASan 构建用于交叉验证。 |
| 增量原生构建可能保留旧补丁 | `-BuildOnly` 也先应用补丁。分发补全 vcpkg 依赖版权文件。 |

## 装配界面用法

“视图 → 装配 · 链接”打开底部停靠面板，与记录面板共用页签。链接页选择 A/B 与类型，输入体坐标锚点或点击“在视口点选”，设置轴、强度、限位后新建。选中已有链接可更新、删除，支持撤销/重做。

锚点页对当前选中刚体添加、拾取、选择、精确修改或删除锚点。绿色点为锚点，选中高亮；视口拾取可吸附已有锚点。接触排除页独立管理部件对。运行时锁定编辑，显示实际关节行程、角度与误差；重置后恢复编辑。

## 范围与未完成项

- 本次完成的是装配表达、界面与对应运行链的修正。真实车辆的驱动副、轴向阻尼、39 对胎唇的专用导入器、整车静置/越障验收仍属于后续 M3–M5，不能把双轮悬架示例称为完整 HSC 整车复现。
- `examples/HSC` 仍是原复现结果的回放项目；并未变成完整的车辆实时重算项目。
- CUDA HSC、ABD、FEM、IPC、CCD、关节已接入，但尚无论文全部场景和规模的等效性或性能证明。
- 论文旋转公式的参考系采用显式约定：冻结当前 Rodrigues 矩阵，求解 `||R_lag F_A alignment - F_B||²`，`alignment=F_A0⁻¹F_B0`。这是相对参考系实现；不同于把论文式 (11) 字面写成 `||R-F_B||²`。导数和整体旋转协变性已测，不能宣称原论文的所有实现细节逐字一致。
