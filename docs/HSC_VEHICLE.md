# HSC 整车接入与验证

## 运行与导入

工具菜单的“导入 HSC 整车装配”从原复现项目读取几何和清单，生成一个独立可编辑场景并开启 HSC。也可直接打开 `examples/hsc-vehicle/ground_1e8.bagua.json` 或 `ground_1e6.bagua.json`。这些是待求解的初始状态；`examples/HSC` 中既有文件仍是原工程运行结果的回放。

若要验证纯 GUI 重建流程：打开 `ground_1e8.bagua.json`，在资产记录页「拆分全部…」，新建场景后逐个「导入组件…」，再用「工具 → 车辆四轮装配向导…」生成四轮悬挂与 7 组胎唇缝合。完整步骤见 [交互与装配操作](INTERACTION.md#从组件到整车纯-gui-流程)。

命令行重新导入：

```powershell
python scripts/ImportHSCVehicle.py --source D:/Collection/HSC_reimpl --output examples/hsc-vehicle --case both
```

导入器只使用 NumPy 读取原始数据，不加载或运行原工程的 Python 物理后端。它拒绝无法精确转换的源姿态，保留虚拟锚点并恢复真实四面体连接。场景和来源哈希可用于重复实验。

## 驱动、阻尼与模拟配置

转动副和移动副可启用驱动，速度分别以 rad/s 和 m/s 指定。目标为 `speed * phase(t)`，其中升速时间 `ramp` 内 `phase=t²/(2*ramp)`，之后 `phase=t-ramp/2`；零升速时间为恒速。原整车四个电机速度 2 rad/s，升速 0.5 s。

移动副的阻尼按上一时步的有符号行程速度计算 `F=-c*v`，通过原生移动副外力能量作用于两端。原复现初始 `last_distance=0` 的约定保持一致。装配属性可编辑驱动、升速时间、驱动强度与阻尼系数；运行诊断显示目标、速度和阻尼力。关闭 HSC 时，Chrono 路径会明确拒绝这些尚未在该路径实现的控制链接。

场景中的 `simulation` 保存原案例的时间步、重力、接触、ABD 刚度、Newton 与线性求解配置，优先于全局设置中的同名参数；设置窗口会提示当前场景覆盖参数。原整车使用 dt=1/30 s、重力 9.8 m/s²、摩擦 0.6、d_hat=1 mm、kappa=1e10、ABD 刚度 1e9。地面使用原生无限平面。安装胎 E=1e10 Pa，地面胎为 1e8 或 1e6 Pa。HSC 使用完整 GPU 稀疏链路和可选的自适应 ABD 逆。

## 整程验收

`BaguaVehicleRunner` 调用与编辑器相同的场景桥接、物理模拟和录制代码，逐步求解并记录，不使用原工程的轨迹。它要求：

- 四个安装轮分别越过所在车道的障碍中心，越过时轮心高于该障碍上界。
- 发生接触，整车后缘超过初始和当前障碍最远边界至少 0.15 m，连续保持 5 帧。
- 胎圈误差 <1e-4 m、移动副和转动副误差 <1e-3 m、悬架行程 <0.151 m、驱动角误差 <0.02 rad、四面体体积比始终为正。

几何验收基于编辑器收到的浮点顶点快照；线性求解器自身使用双精度。`metrics.jsonl` 保存累计最坏误差、四轮跨越情况、最小四面体体积比、求解残差和墙钟时间。只在完整越障及约束检查同时通过时返回成功；失败或中止也会保存可回放的部分记录。

运行目录的 `status.json` 是验证状态依据。[本次验证报告](HSC_VEHICLE_VALIDATION.md) 记录了按用户要求停止的 13 步试跑、约束指标、GPU 内存检查与部分回放。单元测试或原始回放不能代替整程结果。
